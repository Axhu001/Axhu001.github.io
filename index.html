Selected Work

Savonius Wind Turbine CFD Analysis

Objective: Evaluate aerodynamic performance and improve power coefficient using flow control.

Method:

  • 2D transient CFD simulation in ANSYS Fluent
  • k-ω SST turbulence model
  • Sliding mesh for rotor motion
  • Parametric study across tip-speed ratios

Results:

  • Baseline Cp: 0.228 at TSR 1.0
  • Improved to 0.276 at TSR 1.2 (+21%)
  • With deflector: Cp = 0.385 at TSR 1.4 (+69%)

Insight: Flow redirection using deflector increased momentum on advancing blade, improving torque generation.

Thermal Insulation Composite (Bagasse + Plastic)

Objective: Develop low-cost eco-friendly insulation material.

Method:

  • Sandwich composite fabrication
  • Thermal resistance testing
  • Mechanical deformation analysis

Results:

  • ~50% lower deformation vs PVC
  • ~23% higher thermal resistance

Insight: Natural fiber structure enhances insulation while reducing material cost.
