Savonius Wind Turbine CFD Analysis

Method: 2D transient CFD using k-ω SST model with sliding mesh in ANSYS Fluent.

Results:

  • Cp improved from 0.228 → 0.276 (+21%)
  • Further increased to 0.385 (+69%) using deflector

Insight: Flow redirection increases torque on advancing blade.
